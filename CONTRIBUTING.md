# Contributing

Thanks for helping improve Email SMTP/IMAP MCP.

## Development

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm ci`.
3. Make the smallest complete change and add a regression test when behavior changes.
4. Run `npm test` and `npm audit`.
5. Open a pull request describing the problem, the solution, and how you verified it.

Please keep tool inputs backward compatible where practical and never include real email credentials, message contents, or account data in issues, fixtures, or logs.

## Licensing and contributions

Submit only material you are authorised to contribute under the destination project's terms. Identify third-party sources and their licences, retain copyright and attribution notices, and describe upstream modifications. This project uses MIT; its licence does not replace the terms of included third-party material. Review any contribution agreement or developer sign-off required by an upstream project before submitting there. Do not send confidential employer or client material without permission.

Sami reviews origin, licence compatibility, required notices and contributor authority before accepting or sending a contribution. Record that review in the pull request. Programme participants receive this procedure together with the [licence compliance policy](docs/license-compliance/PROGRAMME.md); new responsibilities or material changes require a recorded competence and awareness assessment.
